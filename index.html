Lisamine Outlooki

  1. Uus Outlook / Outlook veebis: paremal ülal hammasratas Seaded → Kontod → Allkirjad → + Uus allkiri.
  2. Klassikaline Outlook (Windows): Fail → Suvandid → Meil → Allkirjad… → Uus.
  3. Anna allkirjale nimi (nt „SL Tervisekeskus“) ja kleebi tekstiväljale: Ctrl + V (Macis Cmd + V).
  4. Kirjuta üle Eesnimi Perenimi, Ametinimetus, +372 000 0000 ja vajadusel e-posti aadress. Ära muuda logo ega aadressi.
  5. Vali see allkiri vaikimisi nii uutele kirjadele kui ka vastustele/edastustele ja salvesta.
  6. Saada endale proovikiri ja kontrolli, et logo ja read on paigas.

Kui „Kopeeri“ nupp sinu brauseris ei tööta: märgi signatuur hiirega nimest kuni logoni ära, kopeeri Ctrl + C ja kleebi Outlooki.
